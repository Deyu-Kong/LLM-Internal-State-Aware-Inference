# PRM800K 单 Probe 短训练报告

基于干净提交 `fb4377d4f99a3341b867d09ed4e608464c02d964`，在 a800 物理 GPU 0 完成一次单随机种子训练。预训练模型为 SmolLM2-135M-Instruct，模型与 tokenizer revision 均为 `12fd25f77366fa6b3b4b768ec3050bf629380bac`。数据为固定版本 PRM800K phase1_train；模型和数据哈希、筛选及分支规则记录于训练清单和 `docs/prm800k_pilot.md`。

训练集长度过滤后包含 192 道原题、699 个步骤（493 正、206 负）；验证集为 50 道原题、192 个步骤（146 正、46 负）。105 个超长样本未截断而排除。只使用已标注的 +1/-1；中性与未知标签不用于监督。没有使用官方测试集或 ProcessBench/PRMBench 标签，但尚未核查跨数据集的原题重合，因此不得声称外部基准无污染。

冻结主模型，训练 827,137 个 LoRA/Probe/Head 参数，执行 100 次 AdamW 更新，单卡 batch 1、梯度累积 4。训练前后所有冻结参数哈希、生成主 KV 和正常生成 logits 相同；187 个可训练张量实际变化。checkpoint 重新加载后预测一致。

| 验证集指标 | 训练前 | 训练后 | 长度/位置基线 |
|---|---:|---:|---:|
| AUROC | 0.5076 | 0.6121 | 0.6554 |
| Average precision | 0.7740 | 0.8111 | 0.8490 |
| F1（阈值 0.5） | 0.2386 | 0.7972 | 0.8571 |
| Brier | 0.2528 | 0.2470 | 0.1745 |
| BCE | 0.6987 | 0.6871 | 0.5288 |

训练集固定 96 样本的 BCE 从 0.6930 降到 0.6886。验证集正例占 146/192；常数先验也达到 F1 0.8639，故不能单凭 F1 宣称有效。训练后 Probe 排序与校准均未超过长度/位置基线。单次小样本试验显示计算路径可以学习，但尚不支持优于强基线或 WP1 假设。Average precision 不是梯形积分 AUPRC。

正式训练循环 52.19 秒，端到端 90.20 秒，PyTorch 峰值 allocated 716,459,520 字节（约 683 MiB；不含 CUDA context 等总进程开销）。结束后 GPU 0、1 均为空闲。CPU 预检通过，a800 测试 70 项通过。本轮使用 GPU 0，没有使用 GPU 1 及其他 GPU。模型为小型低数学能力模型，输入为外部文本重放，不是 on-policy 验证或官方 OTV 复现。

checkpoint 位于本地和 a800 的 `results/prm800k-pilot/prm800k-pilot-001/checkpoint.pt`，大小 3,369,868 字节，SHA256 `0c6eb227b5482c4783192a6ec9f96fb4e6fdc038afe3175a5864f0f9e835c3c4`；不提交到 Git。配置、来源、样本 ID、排除记录、预测、日志与统计归档在 `results/examples/prm800k-pilot/`。完整带题目样本保留在被忽略的运行目录。复现命令、限制与采样规则见 `docs/prm800k_pilot.md`。

下一步应先审计 PRM800K 与独立评测集的原题重合，检查长度过滤和样本偏差，并增加多随机种子与更强模型的预估；不要据此扩大 Probe 数量或宣称研究收益。
